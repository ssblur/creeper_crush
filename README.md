# I Have a Crush on a Creeper?!?

Creeper Crush is an entrant to ModFest 26, and a proof-of-concept for a dating sim / visual novel
engine based on features from my library mod Unfocused.

It is pretty bare-bones at the moment, but it was mostly just a fun thing I threw together 
last-minute to have something for the fest.

Check out IHaCoaC and other ModFest 26 entrants on 
[the ModFest site](https://modfest.net/26/submissions)!
